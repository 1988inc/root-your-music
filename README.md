# Root Your Music

音楽のルーツをたどり、元ネタ候補を聴き比べるWebサイトです。

## Google Analytics

Google Analytics 4（GA4）で基本的なページビューと拡張計測イベントを収集します。

- 測定ID: `G-Q92GPC4R33`
- 設定場所: `index.html` の `<head>` 直後
- 動作確認: デプロイ後、Google Analyticsの「リアルタイム」またはデータストリームの「インストールをテスト」で確認

測定IDは公開Webページに含まれる識別子です。Googleアカウントの認証情報や管理権限はリポジトリに保存しないでください。
